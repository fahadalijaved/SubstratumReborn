## Brand

<img src="brand/reborn-mark.svg" width="64" height="64" alt="The Reborn mark">

- **The mark** is the Substratum swatch deck, redrawn: in a 48 by 48 box, four pill swatches
  (12 by 34, fully rounded) fanned about a rivet at (15, 35) by 66, 44, 22 and 0 degrees, filled
  `#FF9A5C`, `#FFD36E`, `#7B8CFF` and `#A8C7FA` back to front, with a white rivet of radius 3.6.
  The launcher icon uses these fills, with a single-colour layer for themed icons. Inside the app
  the deck takes the theme's colours, so it follows the accent and dynamic colour.
- **The name** is "Reborn" with a quiet "Substratum" under it; in running text, Substratum
  Reborn.
- **The tagline** is "Substratum, reborn for One UI and AOSP".
- **Type and icons:** Google Sans Flex (SIL Open Font License 1.1) and Material Symbols Rounded
  (Apache License 2.0).
